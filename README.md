# Expense Management Go

## Requirement
#### GO Version: 1.26.0

## Installation

```bash
git clone https://github.com/ajaycalicut17/expense-management-go.git
```

```bash
cd expense-management-go
```

```bash
cp .env.example .env
```

```bash
go run ./cmd/server/main.go
```

The application will be accessible at [http://localhost:8080](http://localhost:8080)
